# Messenger app — GeekBrains React course project (2022)

A chat app built during the GeekBrains React course.

- React 17, React Router, Material UI
- State: Redux Toolkit, redux-saga, custom middleware, redux-persist
- Firebase for authentication and realtime data
- Jest and React Testing Library tests for reducers and components
- Developed through feature branches and pull requests

Course project from 2022, no longer maintained.

## Run

```bash
npm install
npm start
```
